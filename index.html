Technical Capabilities

Detailed Feature Directory

A granular breakdown of the technical capabilities and system tools built into the SlotMi desktop platform.

DIR · 01

Customer and Passport Management

Centralized storage for biometric details, passport numbers, issue/expiration dates, and nationality data. Features automatic passport validity checks (flagging passports with under 6 months validity) and family/group case linking for linked appointments.

DIR · 02

Application Workflow Management

Tracks the end-to-end progression of visa applications across standardized stages: Dossier Intake, Queueing, Slot Hunting, Booking Finalized, Documents Printed, and Case Completed. Ensures no client is overlooked during busy consular release windows.

DIR · 03

Multi-Account and Session Management

Execute concurrent booking tasks across multiple provider accounts without browser collision. Each account operates in an isolated environment with encrypted credential storage, automated session token persistence, and localized headers.

DIR · 04

Proxy Management

Integrated proxy pool manager supporting HTTP, HTTPS, and SOCKS5 protocols. Includes automated latency testing, failover retry routines, and per-task rotating IP assignment to maintain resilient connectivity and prevent rate-limiting bottlenecks.

DIR · 05

Notifications and Webhooks

Multi-channel alerting system that notifies agency operators the millisecond an appointment slot is detected or a booking is secured. Dispatches alerts through Telegram Bot API, Discord Webhooks, desktop banner notifications, and audible system alerts.

DIR · 06

Printing Center

Built-in document rendering engine optimized for office paperwork. Outputs formatted appointment confirmation sheets, applicant submission summaries, official payment receipts, and visa application barcode labels without external design tools.

DIR · 07

Payments and Invoicing

Full agency cashier module: record client service fees, consular charges, advance deposits, and outstanding balances. Generates clean PDF/printable invoices and calculates daily, weekly, and monthly office revenue metrics.

DIR · 08

Staff and Permissions

Multi-operator collaboration system designed for tourism offices. Administrators can create staff user accounts, assign specific client cases, and restrict access to financial reports, proxy configurations, or account credentials.

DIR · 09

Audit Logs

Comprehensive, immutable event auditing that timestamps every operation within the application. Logs include slot detection timestamps, booking attempts, configuration changes, staff logins, and financial record alterations for operational compliance.

DIR · 10

Backup and Recovery

Enterprise-grade data safety: local AES-256 encrypted database architecture with path-traversal safeguards. Features automated daily database snapshots and one-click database export/restore to protect office records from hardware failure.
