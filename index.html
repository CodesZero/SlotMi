Questions

Frequently asked

Everything you need to know before getting started.

What operating system does SlotMi require?

Windows only. It installs as a native .exe desktop application.

Is my data safe?

Credentials and API keys are encrypted locally with AES-256, using a key derived from your device’s hardware ID. Core functionality doesn’t send data to external servers.

Which visa portals are supported?

BLS International, TLS Contact, VFS Global, Prenotami, GVC World, IVAC, and Goethe-Institut.

Which countries are supported?

18 origin countries: Egypt, Algeria, Morocco, Tunisia, Mauritania, Pakistan, India, Bangladesh, Nepal, Sri Lanka, Malaysia, Indonesia, Philippines, Thailand, Vietnam, United Kingdom, Netherlands, Turkey, and Uzbekistan.

How do I get notified when a slot opens?

Via a Telegram bot alert, with Windows desktop banner and sound notifications, and an optional SMTP email backup.

Does it handle CAPTCHAs?

Yes — through 2Captcha, CapMonster Cloud, Anti-Captcha, or a custom API endpoint, with manual, automatic or hybrid solving strategies.

Do I need a subscription?

Yes. Activation and an active subscription are required to run automation. Reach out via Telegram or WhatsApp to arrange licensing.
